### Hazard found and fixed: GOAT would have moved
Night Assailant's record has a state-`[]` known gap and a `reuse-upstream` state `[c0]` (`16226796`, which is what Ignis's GOAT list uses). GOAT's parity resolution walks the record's states and takes the first usable substitution, so the moment state `[]` became a `custom-script` GOAT's list changed (`16226796` → `600000003`; hash would have moved). Fix: an exact `reference_identities` entry (`project-ignis-goat`, `provenance_source: ignis-lflists`, `16226796`, upstream `cards-unofficial.cdb + CardScripts`), which the parity code reads ahead of the walk; the code path already exists and eleven records use it. It states a fact the repo already had (GOAT.lflist lists `16226796`, `docs/research/ignis-goat.md` section 5). I did not change any chronology or state.
