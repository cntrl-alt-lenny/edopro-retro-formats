## Open questions

Owner-level, in plain product terms (none changes a list):

1. **Necrovalley at Edison rests on one Konami sentence from before the card was reprinted.** Rule 1 makes the Raging Battle ruling (May 2009) govern over the card's own FAQ line, so the period card negated a non-targeting effect that moves another card out of a Graveyard (Lava Dragon's) at Edison. The ruling predates the January 2010 reprint whose printed text says "target"; no document I read says the reprint changed how Konami ruled, and a printed text is not itself a ruling, so I let the ruling stand. If you read the reprint as replacing it, the difference `d1` comes back for Edison. This is a canonical adjudication on thin evidence, so it is yours to confirm; it moves no list (Necrovalley is a known gap there).
2. **Necrovalley's first change (`c0`, "affect" to "target") may now be a wording change only.** The ruling shows Edison's Necrovalley already negated non-targeting effects that move another card, which was the whole play claim in `c0`. Rule 1 let me narrow that claim; it did not license reclassifying the transition, so it stays `functional`. Whether to make it cosmetic is a further ruling, with no list effect.
3. **The four contact-Fusion cards: whether they could return from banishment.** Rule 2 makes the later FAQ wording govern, but it does not name the banished zone, so the verdict stays `unresolved` and the lists keep what they use now (the strict Project Ignis script for the cannons; YZ-Tank Dragon's undated change already defaults to the modern card). One sentence in the same FAQ (Dimension Distortion, about "Special Summon-only" monsters in general, the same in 2005 and 2008-12) would let them return if you decide it covers them; that is an inference I did not count. If you decide it does, the strict-script lines for the cannons (up to three per list) would go back to the modern card; I did not test that.
4. **Dark Necrofear's remaining claim (the equip must target a face-up monster) probably describes no real difference.** Konami's rulebook says Equip Spell Cards go to "1 face-up monster of your choice" and that a Monster Card treated as an Equip Card follows those rules. That is a general rule, not a ruling on this card, so I left the point `unresolved (general rule only)` rather than reclassify. If you accept a general rule as enough, the transition becomes cosmetic.
5. **Tengu's pool count.** The note said 4,562 cards; the pin, and the pool, are 4563. I removed the number from the note and did not investigate the one-card difference (the research document's "fresh candidate pool" is 4,562).
6. **Rescue Cat, and several other cards, are worded differently in the 2005 and 2008-12 versions of the UDE FAQ** (Rescue Cat: whether you can activate it with fewer than two Beasts in the Deck). No record claims those points, so rule 2 had nothing to decide, but the rule will matter if a later round claims one.
7. **Scope.** I edited one clause of `schemas/erratum.schema.json` (above), and the Tengu note's pool count, which the brief did not name but the same defect class covers.
